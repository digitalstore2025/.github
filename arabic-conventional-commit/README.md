# Arabic Conventional Commit Plugin

💡 **Plugin for IntelliJ IDEA to validate commit messages in Arabic based on Conventional Commit rules.**

---

## Features
- Supports Arabic commit conventions like:
  - `تحسين: ... (feat)`
  - `إصلاح: ... (fix)`
- Ensures commit messages follow proper format.

---

## 💡 دليل المستخدم (بالعربية)
### المميزات
- يدعم كتابة رسائل الالتزام مثل: 
  - `تحسين: ...`
  - `إصلاح: ...`

---

### كيفية الاستخدام
1. حمّل الإضافة إلى IntelliJ.
2. تحقق من صحة التزاماتك باستخدام الواجهة.
3. اتبع قواعد Conventional Commit.
